# acos-bash-lab
# Архивация логов на Bash

Скрипт `archive_logs.sh` проверяет суммарный размер обычных файлов непосредственно в папке `log`. Если размер превышает заданный процент от условного лимита, скрипт выбирает самые старые файлы по времени изменения, пока расчётный размер не станет меньше либо равен порогу. Выбранные файлы помещаются в один архив `.tar.gz` в папке `backup`. После проверки архива оригиналы удаляются.

Это логический лимит для расчёта; скрипт не устанавливает квоту файловой системы. Вложенные каталоги и символьные ссылки не учитываются.

## Запуск

Нужны Linux, Bash 4.4+ и стандартные GNU-утилиты. Папки `log` и `backup` должны существовать и не быть вложенными друг в друга.

```bash
bash archive_logs.sh "$HOME/Desktop/log" "$HOME/Desktop/backup" 10 60
```

Аргументы: путь к `log`, путь к `backup`, условный лимит в МиБ и порог в целых процентах от 0 до 100. В примере архивация нужна, когда файлы в `log` занимают больше 60% от 10 МиБ.

## Запуск в Windows

`archive_logs.bat` — версия скрипта для `cmd.exe` с теми же аргументами и той же логикой. Нужны Windows 10 1803+ и встроенный `tar.exe`. Лимит в этой версии не больше 1000000 МиБ, а отдельный файл в `log` — не больше 999999999 байт: арифметика `cmd` 32-битная.

```bat
archive_logs.bat "C:\logs" "C:\backup" 10 60
```

## Тесты

```bash
bash -n archive_logs.sh
bash -n test_archive_logs.sh
bash test_archive_logs.sh ./archive_logs.sh
```

В Windows:

```bat
test_archive_logs.bat
```

Пять тестов в обеих версиях проверяют аргументы, размер ниже порога без учёта вложенных папок и ссылок, точное равенство порогу, выбор старых файлов и содержимое архива, а также ошибки системных команд. Во всех тестах папка `log` весит не меньше 0,5 ГБ (512 МиБ при лимите 1024 МиБ), и каждый тест проверяет это перед запуском скрипта. Тесты работают в собственной временной папке и не обращаются к пользовательским `log` и `backup`; нужно около 2 ГБ свободного места, в Bash-версии файлы разреженные и почти не занимают диск.

Скрипт рассчитан на учебный сценарий, в котором файлы не изменяются параллельно с архивацией.
